계정 및 데이터 삭제

앱에서 삭제: Bookey 로그인 → 나 → 설정 → “계정 영구 삭제”를 선택하고 확인합니다.

앱에 로그인할 수 없다면 가입 이메일과 삭제 요청 의사를 support@bookey.site로 보내 주세요. 본인 확인 후 처리 결과를 안내합니다.

삭제하면 이메일·비밀번호·본인인증 정보, 소셜 로그인 연결, 푸시 알림 토큰, 로그인 토큰, 알림, 프로필 방문 기록, 고객문의, 올린 프로필 사진을 지우고 계정을 종료합니다. 법령상 보관 의무가 있는 거래 기록은 정해진 기간 동안 따로 보관하며, 다른 회원과 함께 쓰는 공간의 기록은 작성자가 “탈퇴한 사용자”로 처리되어 남을 수 있습니다. 백업본에는 최대 30일 동안 남을 수 있습니다. 앱 마켓 구독은 계정 삭제와 별도로 해당 스토어에서 해지해야 합니다.

고객지원

앱에서 문의: 로그인 → 나 → 설정 → “고객문의”에서 자주 묻는 질문을 보거나 문의를 남기고 답변을 확인할 수 있습니다. 환불은 ‘결제·구독’ 유형으로 남겨 주세요.
